{"case_id": "dev-source-baseline-definition", "proposed_text": "A source baseline identifies the material against which a proposal is reviewed. It serves as the fixed reference point that a proposal is measured against during review, establishing what content constitutes the established or authoritative version at the time of evaluation. In this way, the source baseline anchors the review process to a defined body of material, so that any proposed changes can be assessed in relation to that consistent reference rather than against an undefined or shifting set of content."}
