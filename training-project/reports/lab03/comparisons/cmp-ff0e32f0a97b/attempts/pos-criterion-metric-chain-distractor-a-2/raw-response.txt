  "proposed_text": "In evaluation design, a criterion specifies the quality property or requirement that the system must satisfy, such as reliability, security, or performance, while a metric is a precisely defined measurement that yields a numeric or observable value which can be compared against the criterion to decide whether the property holds; thus, metrics act as the quantitative tool used to test each criterion, for instance a criterion like 'fast response time' would be evaluated using a metric such as 'average query execution time in milliseconds', where meeting the criterion means the metric falls within an acceptable range."
